# Booking Management System

A Spring Boot based Booking Management System using PostgreSQL.

## Technologies

- Java
- Spring Boot
- PostgreSQL
- Hibernate
- Spring Security
- JWT
- HTML CSS

## Features

- User Registration and Login
- JWT Authentication
- Create Booking
- Update Booking
- Delete Booking
- Manage Booking Status

## How to Run

1. Clone repository
2. Configure PostgreSQL database
3. Run Spring Boot application
